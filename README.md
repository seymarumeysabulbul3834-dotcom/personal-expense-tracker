# Personal Expense Tracker

A simple personal finance application developed with Python.

## Features

- Add income
- Add expenses
- View all transactions
- Calculate current balance
- Delete transactions
- Track transaction dates
- Automatically save data using JSON
- Validate user inputs

## Technologies Used

- Python
- JSON
- Git
- GitHub

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python main.py

## Project Purpose

This project was developed to practice Python programming,
functions, data structures, file handling and GitHub.
